# Gallery responsive

Bộ sưu tập tám minh họa phong cảnh được dựng bằng CSS, không cần tải ảnh ngoài. CSS Grid hiển thị bốn cột ở màn hình trên 700px, hai cột ở màn hình từ 501px đến 700px và một cột ở màn hình tối đa 500px.

## Chạy thử

Mở `index.html` trong trình duyệt và kiểm tra ở các độ rộng khác nhau, đặc biệt quanh hai breakpoint 700px và 500px.
